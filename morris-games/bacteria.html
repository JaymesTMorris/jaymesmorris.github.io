About Bacteria

Bacteria is a Commodore 128 arcade game written by Leonard Morris and published in COMPUTE!'s Gazette Issue 69, March 1989. The game runs exclusively in C128 native mode using the 40-column display.

Players use a joystick (Port 2) to control their character and battle enemies in fast-paced action gameplay. Leonard Morris served as both coder and graphics artist on this title.

This game is preserved here as part of the Morris Games Archive, a family preservation effort maintained by Jaymes Morris (Leonard's grandson).

How to Play

Starting: Click Start Game to initialize the C128 emulator. When the BASIC prompt appears, load the game from disk using the LOAD command shown above the screen.

Movement: Use the arrow keys to move in four directions (mapped to joystick Port 2).

Fire: Press Left Ctrl to fire or activate.

Objective: Defeat enemies and survive as long as possible. Specific scoring and game rules will be visible in-game.

Tip: Click Fullscreen after the emulator loads for the best experience. Click inside the emulator canvas to ensure it captures keyboard input.
