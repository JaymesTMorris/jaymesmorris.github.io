Game Library

Seven Commodore 128 games preserved from RUN and COMPUTE!'s Gazette magazines

Mazamorf
RUN Magazine · Fun Pak 128 · 1988

A Commodore 128 maze arcade game. Navigate through treacherous mazes while avoiding enemies using a joystick.

Arcade Joystick C128
Cubix 2
RUN Magazine · Fun Pak 128 · 1988

A Commodore 128 puzzle game based on Rubik's Cube mechanics. Rotate faces and solve the cube using keyboard controls.

Puzzle Keyboard C128
Cubix 3

The sequel to Cubix 2 with expanded puzzle mechanics. A keyboard-driven Commodore 128 puzzle game.

Puzzle Keyboard C128

A logic puzzle game for the Commodore 128. Arrange squares in the correct order using keyboard input.

Puzzle Keyboard C128

A joystick-driven arcade game for the Commodore 128. Battle enemies in fast-paced action gameplay.

Arcade Joystick C128
Brusher
COMPUTE!'s Gazette · Issue 70 · April 1989

A Commodore 128 arcade game controlled with a joystick. Navigate and clear the screen of obstacles.

A joystick-controlled endurance arcade game for the Commodore 128. Run, dodge, and survive as long as you can.

About This Archive

These games were written by Leonard Morris, a hobbyist programmer who published seven Commodore 128 games across two major American computer magazines between 1988 and 1989. He is credited as both coder and graphics artist on all titles. Leonard passed away in 2018.

This archive is maintained by his grandson, Jaymes Morris, as a family preservation effort.

System note: All games require a Commodore 128 in native C128 mode with a 40-column display. In-browser playback uses a WASM build of the VICE C128 emulator (x128).
