About Mazamorf

Mazamorf is a Commodore 128 maze arcade game written by Leonard Morris and published in RUN magazine as part of the Fun Pak 128 collection in 1988. The game runs exclusively in C128 native mode using the 40-column display.

Players navigate their character through maze environments while avoiding or defeating enemies, using a joystick connected to Port 2. Leonard Morris served as both coder and graphics artist on this title.

This game is preserved here as part of the Morris Games Archive, a family preservation effort maintained by Jaymes Morris (Leonard's grandson).

How to Play

Starting: Click Start Game to initialize the C128 emulator. The Fun Pak 128 disk will autoboot and display a game selection menu. Press the letter key shown next to Mazamorf on the menu to load the game.

Movement: Use the arrow keys to move in four directions (mapped to joystick Port 2).

Fire: Press Left Ctrl to fire or activate.

Objective: Navigate the maze, evade enemies, and reach the goal. Collect items and score points to advance through levels.

Tip: Click Fullscreen after the emulator loads for the best experience. Click inside the emulator canvas to ensure it captures keyboard input.

Fun Pak 128 was a disk companion published by RUN magazine, containing several original Commodore 128 games. The disk uses an autoboot menu allowing players to select from multiple titles including Mazamorf, Cubix 2, and Cubix 3, all written by Leonard Morris.

RUN magazine was a leading American publication for Commodore computer enthusiasts, published from 1984 to 1993.
